## ✨ المميزات الرئيسية (Features)
- **باقات كاترنج جاهزة ومتنوعة**: باقة كتب الكتاب الملكية، باقة الزفاف الماسية، باقة الحلويات الشرقية، وباقات مخصصة للمؤتمرات والشركات.
- **مُنشئ العبوات المخصصة (Custom Box Builder)**: تصميم العبوة خطوة بخطوة واختيار المكونات، نوع التغليف، وتخصيص عبارة شريط الستان وكارت التهنئة.
- **حاسبة ميزانية المناسبة (Event Budget Calculator)**: حساب التكلفة التقديرية حسب عدد المعازيم ونوع المناسبة.
- **مستشار الكاترنج الذكي (AI Catering Advisor)**: مدعوم بـ Gemini AI لتقديم اقتراحات منيو مخصصة تناسب نوع المناسبة وميزانيتها.
- **نظام حجز وتتبع الطلبات (Orders Management)**: حجز فوري مع دعم تأكيد الطلبات عبر واتساب والدفع الإلكتروني (InstaPay / كاش عند الاستلام).
- **فواتير تفصيلية جاهزة للطباعة والتنزيل (Invoice Modal)**.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Motion (Framer Motion)
- **Icons**: Lucide React
- **Backend**: Node.js + Express (Serverless compatible on Vercel)
- **AI Integration**: Google Gen AI SDK (`@google/genai`)

---

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم

# 2. تشغيل سيرفر التطوير
```
